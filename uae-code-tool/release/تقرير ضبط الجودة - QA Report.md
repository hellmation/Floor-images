# تقرير ضبط الجودة — بطولة كود الإمارات | QA Report — UAE Code Championship

**التاريخ / Date:** 2026-11-06 · **الإصدار / Build:** 1.1

## المنهجية / Method

1. أربع مراجعات مستقلة للشيفرة والبيانات (منطق الاحتساب والتخزين، الواجهة وثنائية اللغة وإمكانية الوصول، تصدير Excel، سلامة البيانات الأساسية) — 120 ملاحظة.
2. اختبارات سيناريو آلية في متصفح حقيقي (Playwright) على مجلد مشترك محاكى يعمل عليه مستخدمان في الوقت نفسه.
3. إصلاح → إعادة بناء → إعادة اختبار حتى نجاح جميع السيناريوهات.

Four independent audits (logic and storage, UI/i18n/accessibility, Excel export, master data) produced 120 findings. Automated browser scenarios ran on a simulated shared folder with two concurrent users. Every finding rated high or medium was fixed; the rest were fixed where cheap or documented below.

## ما تم إصلاحه / What was fixed

### سلامة البيانات على المجلد المشترك / Data safety on the share
- قراءة متعثرة لملف الإعدادات (قفل مؤقت على الشبكة) كانت قد تُعيد الإعدادات إلى القيم الافتراضية. الآن لا يُعاد الملف إلا إذا كان غير موجود فعلاً.
- حفظ الإجابات يدمج مع ما على القرص (الأحدث لكل كود/ملاحظة) ويمر عبر طابور واحد، فلا يمحو حفظٌ سريعٌ حفظاً آخر، حتى من تبويبين للشخص نفسه.
- سجل الأحداث صار ملفاً لكل شخص (data/audit/) بدل ملف مشترك يتسابق عليه الجميع.
- تعديل الإعدادات من جهازين: يُرفض الحفظ القديم مع رسالة واضحة وإعادة تحميل بدل الكتابة فوق الأحدث.
- فقدان إذن المجلد أو تعطل القراءة يظهر في شريط أعلى الصفحة مع زر إعادة الاتصال، وكل عملية حفظ فاشلة تُظهر رسالة بدل الصمت.
- الملف الأقدم من البيانات يرفض الفتح بدل تخريبها؛ الترحيل من إصدار سابق يحافظ على الربط اليدوي.

### منطق التقييم / Evaluation logic
- الاعتماد مرتبط بالإرسال نفسه (من ومتى)، فلا يلتصق اعتماد قديم بإجابة جديدة ولا تؤثر فروق الساعة بين الأجهزة.
- الإجابة المعتمدة هي الأكثر تقدماً (معتمد > مُرسل > مُعاد > مسودة) ثم إجابة المُسند إليه؛ مسودة فارغة لم تعد تُخفي إجابة مُرسلة.
- المستخدم المعطَّل لا يبقى مُسنداً إليه؛ تنتقل أكواده تلقائياً مع تحذير قبل التعطيل.
- إغلاق الدورة يثبّت الإسناد، فلا تتغير أرقام الدورات المغلقة عند تعديل الربط لاحقاً.
- الترحيل من دورة سابقة لا ينقل علامات "يحتاج توضيح".
- الفجوات تُحسب بالتعريف نفسه في اللوحة والجدول والتصدير.
- الترتيب: النتائج المتساوية تتشارك المركز.
- المراجعة والإعادة لا تعمل في دورة مغلقة؛ إعادة فتح كود معتمد تطلب تأكيداً.

### الواجهة / UI
- تحذير قبل مغادرة صفحة فيها تغييرات غير محفوظة (داخل الأداة وعند إغلاق التبويب).
- رسائل واضحة عند دورة مغلقة أو في التخطيط، وعند تحرير كود مُسند لشخص آخر.
- روابط الأدلة تُتحقق (http/https/مسار مشترك \\\\)، وتُحوَّل مسارات الشبكة إلى روابط قابلة للفتح.
- الشاشات الصغيرة بلا تمرير أفقي في اللغتين؛ مُبدّل الدورة متاح على الهاتف.
- حقول الإدارة تحفظ عند الخروج من الحقل بدل كل ضغطة مفتاح؛ الأرقام تُتحقق (لا سالب ولا فارغ).
- بحث القائمة السريعة يشمل اللغتين ونصوص المتطلبات ويتجاهل التشكيل والهمزات.
- إمكانية الوصول: حوارات بحبس التركيز، تسميات لكل حقل وزر، تباين ألوان مطابق لـ WCAG AA في الوضعين، تواريخ موحدة.
- حالات فارغة وأزرار "إزالة التصفية" في التصفح والملاحظات والربط.

### تصدير Excel / Excel export
- عمود الدورة ورقم ترتيبي على كل ورقة؛ ورقة المتطلبات صالحة للجداول المحورية (الوزن، المُسند إليه، المشروع، نتيجة الكود، الاعتماد، تاريخ الإرسال).
- بيانات المراجع لا تُصدَّر إلا للمراجعة السارية؛ الجاهزية والإنجاز صفان منفصلان؛ طلبات التوضيح بلا رد عدٌّ مستقل.
- نعم/لا موحدة، التواريخ بالتوقيت المحلي، قوائم منسدلة للتقييم والحالة، لا صفوف فارغة وهمية.

### البيانات / Data
- 8.5.5: المستند يكرر المتطلب الثاني — أُدرج مرة واحدة مع علامة.
- 8.8.1: معايير الرصد المطبوعة لا تخص هذا المعيار — أُبقيت كما في المستند مع علامة ظاهرة.
- إزالة تشكيل منزاح في 88 كوداً (أثر استخراج)، وتوحيد الترجمة الإنجليزية للنصوص العربية المتطابقة، وتوحيد "UAE PASS".

## الجولة الثانية (7 نوفمبر) — ثبات التحديد / Round 2 (7 Nov) — selection stability

البلاغ: «أختار نعم فتُلغى وحدها». تم استنساخ الحالة آلياً وإغلاق كل مساراتها:
- تحديث الخلفية (كل 90 ثانية) أو زر التحديث أثناء التحرير: التحديد يبقى. ✓
- الحفظ التلقائي للملاحظة الشخصية أثناء التحرير: يبقى. ✓
- شخص آخر يحفظ الكود نفسه أثناء تحريرك: تعديلاتك تبقى ويظهر شريط «الاحتفاظ بتعديلاتي / تحميل النسخة الأحدث». ✓ (كان هذا يستبدل تحديدك بتحديده ثم يحفظه باسمك.)
- النقر أثناء حفظ جارٍ أو أثناء قراءة بطيئة من المجلد: لا يُفقد شيء ويبقى «غير محفوظ» حتى الحفظ التالي. ✓
- تعديل المدير للإعدادات أثناء تحريرك: يبقى. ✓

تحصينات إضافية في طبقة التخزين: دمج ثلاثي لا يتأثر بفروق الساعة بين الأجهزة؛ القراءة البطيئة لا تُرجع نسخة أقدم فوق ما حُفظ للتو؛ كل كتابة تُقرأ بعد حفظها للتأكد منها ويُعاد الدمج إن كتب غيرك في اللحظة نفسها؛ إعادة المحاولة مرة عند تعثر قراءة مؤقت على الشبكة؛ لا تُكتب الإعدادات الافتراضية أبداً فوق مجلد فيه بيانات؛ الملف الأقدم من البيانات يصبح للقراءة فقط؛ تعارض المراجعات بين مديرين يُكتشف؛ فقدان إذن المجلد يُطلب تجديده فوراً؛ تغيير الدورة أو التحديث يحترم تحذير التغييرات غير المحفوظة؛ الوضع المحلي يبلّغ عن أي فشل حفظ أو تلف بدل الصمت.

Report: "I select Yes and it gets unselected." Reproduced and closed on every path (background refresh, note autosave, another person saving the same code, clicks during an in-flight save or slow read, admin settings changes). Storage additionally hardened: three-way merge immune to clock skew, slow reads never roll back fresh writes, every write is verified and re-merged if someone wrote meanwhile, transient read errors retried, defaults never written over existing data, older files become read-only against newer data, review conflicts detected, lost permission re-requested immediately, cycle switch and refresh honour the unsaved-changes guard, local mode surfaces save failures.

## الجولة الثالثة (11 نوفمبر) — اختفاء الحقول / Round 3 (11 Nov) — hidden form fields

البلاغ: «المرشحات غير ظاهرة». السبب: قاعدة تنسيق لخلفية صفحة الدخول (المتحركة) كانت تحمل الاسم نفسه `field` الذي تحمله حقول النماذج، فأخفت كل حقل يستخدمه منذ 3 نوفمبر: مرشحات «أعمالي»، وحقول المتطلب في صفحة الكود (الإدارة، المشروع، الخدمة، الملاحظة، تبرير «لا ينطبق»)، ونموذج الدورات، وحقول الجهة في الإعدادات. أُعيدت تسمية قاعدة الخلفية، وأُضيف اختبار يقيس الظهور الفعلي (الحجم والشفافية واستقبال النقر) لكل حقل في كل صفحة، لأن اختبارات الوظائف السابقة كانت تنجح على حقول شفافة.

Report: "the filters are not visible." Cause: the landing page's animated background used the same class name as form fields, hiding every field since 3 Nov (My work filters, per-requirement fields on the code page, the Cycles form, entity fields in Settings). The background class was renamed and a computed-visibility test (size, opacity, pointer events) now runs on every page, since the functional tests had been passing against transparent fields.

## ملاحظات معروفة / Known limits
- سجل الأحداث للعرض فقط؛ لا يُستخدم في الاحتساب.
- الشخص نفسه من جهازين في اللحظة نفسها: يُدمج بالأحدث لكل كود (لا يُفقد شيء، لكن قد يفوز آخر تعديل على الكود نفسه).
- أسماء المحاور الفرعية الإنجليزية ترجمة غير رسمية.
