أدعوكم لحضور اجتماع انطلاق **التقييم الذاتي للهيئة الاتحادية للضرائب وفق كود الإمارات للخدمات الحكومية وتصفير البيروقراطية**، وهو الإطار الصادر عن حكومة دولة الإمارات لقياس جاهزية الجهات الحكومية والتزامها بمتطلبات الخدمات الحكومية الاستباقية والسلسة. يضم الكود **8 محاور** و**60 محورًا فرعيًا** و**371 معيارًا**، ولكل معيار متطلبات ومعايير رصد محددة يجب تقييمها وتوثيقها بالأدلة.

## أهداف الاجتماع

1. التعريف بالكود ومحاوره الثمانية ومنهجية التقييم والاحتساب.
2. استعراض الأداة الداخلية للتقييم («بطولة كود الإمارات») وطريقة العمل عليها.
3. الإعلان عن توزيع المعايير على أعضاء الفريق بحسب المشاريع.
4. اعتماد خطة العمل والجدول الزمني للدورة الأولى (خط الأساس).

## منهجية التقييم باختصار

- يُقيَّم كل متطلب على حدة بإحدى القيم: **نعم / جزئي / لا / لا ينطبق** (مع إلزامية تبرير «لا ينطبق»).
- الاحتساب: نعم = 100، جزئي = 50، لا = 0، وتُستبعد حالات «لا ينطبق»، مع ترجيح بحسب مستوى الأثر (عالٍ 3، متوسط 2، منخفض 1).
- الأدلة تُرفق **كروابط** على مجلدات الأدلة في المجلد المشترك، ولا تُرفع أي ملفات خارج أنظمة الهيئة.
- أي معيار غير واضح يُعلَّم بخيار «يحتاج توضيح» لمناقشته معي قبل اعتماده.
- دورة العمل: مسودة ← إرسال ← مراجعة واعتماد (أو إعادة مع ملاحظات).

The Code comprises **8 pillars**, **60 sub-pillars** and **371 codes**, each with specific requirements and monitoring criteria that must be assessed and evidenced.

## Meeting objectives

1. Introduce the Code, its eight pillars, and the assessment and scoring methodology.
2. Walk through the internal assessment tool ("UAE Code Championship") and how to work in it.
3. Announce the distribution of codes across the team, based on project ownership.
4. Agree the work plan and timeline for the first cycle (baseline).

## Methodology in brief

- Each requirement is answered individually: **Yes / Partial / No / Not applicable** (a justification is mandatory for "Not applicable").
- Scoring: Yes = 100, Partial = 50, No = 0; "Not applicable" items are excluded; weighted by impact level (High 3, Medium 2, Low 1).
- Evidence is attached **as links** to the evidence folders on the shared drive. No files are uploaded outside FTA systems.
- Any unclear code is flagged "Needs clarification" so we can discuss it before approval.
- Workflow: Draft → Submit → Review and approve (or return with comments).
